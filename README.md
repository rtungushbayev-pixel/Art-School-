# Школа искусств и дизайна им. А. Кастеева — мобильное приложение

Мобильное приложение (React Native / Expo) для учеников и руководства
художественной школы.

## Возможности

**Ученикам:**
- расписание занятий по группам
- домашние задания и сдача работ на проверку
- лента портфолио — публикация фото работ, лайки, комментарии
- объявления от администрации
- профиль ученика с отметкой, куда поступил(а) / планирует поступать

**Руководству:**
- рассылка объявлений (всем / ученикам / сотрудникам / конкретной группе)
- учёт посещаемости по группам и датам
- модерация загруженных в портфолио работ (одобрить / отклонить)

## Стек

- Expo (React Native, TypeScript), React Navigation
- Supabase: Postgres + Auth + Storage + Row Level Security

## Запуск

1. Создайте проект на [supabase.com](https://supabase.com).
2. Выполните SQL-миграции из `supabase/migrations` (SQL editor в Supabase
   Studio или `supabase db push`, если используете Supabase CLI), в
   указанном порядке: `0001_init.sql`, затем `0002_storage.sql`.
3. Скопируйте `.env.example` в `.env` и укажите `EXPO_PUBLIC_SUPABASE_URL`
   и `EXPO_PUBLIC_SUPABASE_ANON_KEY` из настроек вашего проекта Supabase.
4. Установите зависимости и запустите:

   ```bash
   npm install
   npm run start
   ```

   Откройте приложение в Expo Go (iOS/Android) или через `npm run web`.

## Структура проекта

```
src/
  components/     переиспользуемые UI-компоненты
  hooks/          useAuth (сессия + профиль)
  lib/            клиент Supabase, запросы к постам/объявлениям
  navigation/     навигация: Auth / Student / Staff
  screens/
    auth/         вход и регистрация
    student/      экраны ученика
    staff/        экраны руководства
    shared/       общие экраны (профиль, публикация, редактирование)
  theme/          цвета и отступы
  types/          типы таблиц базы данных
supabase/
  migrations/     SQL-схема, RLS-политики, хранилище файлов
```

## Роли и данные

Роль (`student` / `staff`) выбирается при регистрации и хранится в
`profiles.role`. Группы учеников (`groups`, `group_members`) создаются
и назначаются администрацией напрямую через Supabase Studio (управление
группами и назначение учителей — следующий шаг развития приложения).
